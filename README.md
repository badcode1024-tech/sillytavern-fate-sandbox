# 命运沙盘 Fate Sandbox

> 专属于 SillyTavern 的高沉浸感复杂世界模拟与养成插件。
> 本地抽卡 + AI 润色，六大功能模块：命运沙盘 / 圣女印记 / 交易所 / 救世录 / 法则镌刻 / 卡池管理后台。

---

| 0 | 命运沙盘 | 四大核心文本框（终焉之劫/灾厄侵蚀度/灾厄形态/契约勇者）+ 重塑因果/旧世复苏/异界锚定/异界特典/越级挑战 + 终局结算 |

## 二、目录结构

```
fate-sandbox/
├── manifest.json          # 插件清单（酒馆识别）
├── index.js               # 入口，注册 init/onRemove
├── style.css              # 全部样式（日夜双皮肤 + 响应式）
├── README.md              # 本文档
└── src/
    ├── pools.js           # 全部卡池数据（世界背景/难度/灾难/邪恶势力/勇者外观/性格/核心/同人/卡牌定义/积分表）
    ├── draw.js            # 本地随机抽卡引擎（密码级随机源）
    ├── store.js           # 数据持久化层（多端适配 + 卸载清理）
    ├── ai.js              # AI 调用层（复用主API/外接 + 记忆宫殿联动 + 重试）
    └── ui.js              # UI 层（悬浮球 + 六大分栏 + 卡牌翻转 + 主题）
```

## 三、安装（三种环境通用）

### 1. 本地酒馆（SillyTavern 桌面版）

1. 将整个 `fate-sandbox` 文件夹复制到酒馆扩展目录：
   ```
   SillyTavern/data/<user>/extensions/
   ```
   最终路径形如：`.../extensions/fate-sandbox/manifest.json`
2. 重启酒馆，或在「扩展」面板中点击「重新扫描」。
3. 在扩展列表中启用「命运沙盘 Fate Sandbox」。

### 2. 云酒馆 / TauriTavern

- **云酒馆**：通过后台「扩展上传」或直接 SSH/文件管理器把 `fate-sandbox` 上传到 `data/<user>/extensions/` 即可。
- **TauriTavern**：与本地酒馆完全一致，`manifest.json` + 纯 JS/CSS 无原生依赖，直接放入扩展目录。

> 三端均无需构建步骤，插件为纯 ES Module + CSS，加载即用。

## 四、悬浮球与静默模式

- **安装即用**：插件加载后悬浮球立即显示，**不识别角色卡名称**。
- **初始位置**：屏幕右侧边缘垂直正中间，完整显示、不透明、不回缩。
- **首次交互后回缩**：第一次点击打开面板（或拖动）之后，关闭面板时悬浮球平滑缩回屏幕，只露出 2/5 面积。
- **关闭悬浮球**：悬浮球右上角有 ✕ 按钮（hover 时出现），点击即隐藏。重新开启的三处入口：
  1. 酒馆「扩展(Extensions)」面板 → 「命运沙盘 Fate Sandbox」→ 勾选「显示悬浮球」；
  2. 插件面板「法则镌刻」分栏 → 「悬浮球显示」开关；
  3. 静默模式同在这两处可切换。
- **静默模式**：点击悬浮球展开面板，右上角（或「法则镌刻」分栏）的静默开关可一键关闭插件。开启静默后：
  - 悬浮球变灰降透明度；
  - 停止所有 AI 发送/接收（重Roll、结算、故事生成、楼层监控全部暂停）；
  - 不删除任何本地数据，关闭开关即恢复。
- 悬浮球支持自由拖动，松手自动吸附右缘、只露出 2/5。

## 五、数据持久化与卸载

- 所有数据（积分、卡牌、存档、设置、卡池覆盖）写入酒馆 `extensionSettings` 的 `__fateSandbox` 命名空间，随酒馆自动保存。
- **卸载**：`onRemove()` 钩子会移除所有 DOM 节点并调用 `store.clearAll()` 清空 `__fateSandbox`，**不留残余**。

## 六、AI 调用配置

默认「复用酒馆主 API」（走 `generate("quiet", ...)` 静默生成，不污染聊天）。

切换外接 API：
1. 打开「法则镌刻」→「API 配置」→ 选择「外接独立 API」。
2. 填入 OpenAI 兼容接口地址（`https://api.xxx.com`）、Key（可选）、模型名。
3. 点击「铭刻法则（保存）」。

1. 「法则镌刻」最底部有一个装饰符号 `✦`，点击它。

## 八、抽卡与积分规则（内置）

- 世界背景 / 灾难 / 邪恶势力 / 勇者外观·性格·核心 均从 `pools.js` 对应卡池本地随机抽取。
- 勇者：正面性格抽 3、负面抽 1、中性抽 1、核心抽 1，外观各维度抽 1。
- 积分奖惩表见 `pools.js` → `REWARD_TABLE`。
- 卡牌价格见 `pools.js` → `CARD_DEFINITIONS`。

## 八点五、星级评定与 100 层防死循环机制

### 星级评定标准（AI 结算时强制注入 Prompt）
- ⭐ **一星（隐患留存）**：世界勉强拯救完成，但根基未稳，旧的邪恶势力随时可能卷土重来。
- ⭐⭐ **二星（中规中矩）**：世界成功拯救，平稳过渡，秩序恢复原点。
- ⭐⭐⭐ **三星（完美拯救）**：完美拯救，世界迎来新生与实质繁荣。
- 任务成功 → 下一任务难度**升一级**；失败 → **停留原等级**。
- 判定结果以 JSON（`{success, star, points, reason}`）返回，插件本地解析并按 `REWARD_TABLE` 结算积分。

### 100 层硬性强制结算
- 插件每 1.5 秒读取当前酒馆聊天楼层数（`ctx.chat.length`）并本地计数。
- 切换聊天/开启新任务时自动重置计数。
- 达到 **第 100 层**仍未主动结算 → 弹出「因果超过临界」警告，强制拉起结算流程。
- 强制结算时 Prompt 注入失败判定规则：**邪恶势力未被彻底消灭/驱除 → 直接判「任务失败」（0星），按对应难度扣除惩罚积分**。
- 命运沙盘分栏顶部有「界域深度」进度条，≥70 层变红预警。

## 十、常见问题（FAQ）

**Q：悬浮球不显示？**
A：插件已改为「安装即用」，不再识别角色卡名。若看不到，检查是否在酒馆「扩展」面板里被关闭了「显示悬浮球」，或悬浮球右上角 ✕ 被误触。

**Q：抽卡后文本框没更新？**
A：AI 生成失败时会弹出「界域演化失败」，附「再次手动结算」按钮。检查 API 配置与网络。

**Q：长列表滑动到一半回弹？**
A：已在 `.fs-body` 上设置 `overscroll-behavior: contain` 与 `-webkit-overflow-scrolling: touch`，修复触顶/触底阻尼失效。

**Q：卸载后数据还在吗？**
A：不会。卸载时自动清空 `__fateSandbox` 命名空间。
